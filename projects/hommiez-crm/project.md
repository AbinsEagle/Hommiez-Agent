# Hommiez CRM + Storefront (e-commerce)

Repo: /home/rona/hommiez-backend-producthunt-crm
GitHub: AbinsEagle/hommiez-backend-producthunt-crm (private)

What it is: the e-commerce side of Hommiez. A product-hunting CRM and a public mobile storefront for the Hommiez home-products brand. Scrape competitor best-sellers, score demand, groom listings, plan margins, trial live, keep winners and kill losers. Product lifecycle: raw, grooming, planning, testing, winner or killed. See README.md and SYSTEM_OVERVIEW.md in the repo.

Stack: FastAPI + SQLAlchemy backend, React 19 + Vite admin, Jinja2 storefront, Supabase (Postgres and Auth), hosted on Vercel.

Accounts: this project has its own Supabase account, separate from the PMP Exam Simulator one. Keys live only in this repo's .env.

Separate from the Hommiez Agent project, which is the fabrication house side.
